# F1 Driver Position Prediction

This project analyzes historical Formula 1 race data to predict a driver’s finishing position in a race using machine learning. It combines race-level, driver-level, and contextual features to identify patterns that influence race outcomes.

The core work is documented in the Jupyter notebook **My F1 story.ipynb**, where the data is explored, cleaned, and transformed into model-ready features. Multiple predictive signals such as driver performance trends, race conditions, and historical results are evaluated to estimate finishing positions.

The project also includes an application script (**app.py**) that allows users to input relevant race and driver information and generate predicted finishing positions based on the trained model.

Overall, the project demonstrates an end-to-end data analytics workflow—starting from raw sports data, progressing through exploratory analysis and modeling, and ending with an interactive prediction interface—applied to real-world Formula 1 racing data.
